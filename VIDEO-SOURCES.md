Историческо прекодиране за v0.14.0 с безплатния FFmpeg от оригинала (WebM вече не се доставя):

```bash
ffmpeg -i original.MP4 -ss 0 -t 10.5 -map 0:v:0 \
  -vf 'scale=854:480,fps=24' -c:v libx264 -preset slow -crf 30 \
  -profile:v main -level 3.1 -pix_fmt yuv420p -an -map_metadata -1 \
  -movflags +faststart parallel-bar-dips-v1.mp4
ffmpeg -i original.MP4 -ss 0 -t 10.5 -map 0:v:0 \
  -vf 'scale=854:480,fps=24' -c:v libvpx-vp9 -b:v 0 -crf 44 \
  -row-mt 1 -an -map_metadata -1 parallel-bar-dips-v1.webm
```

Плеърът използва съвместимия с iOS MP4, `controls`, `playsinline`, `preload="none"`, без autoplay. Предишният WebM беше по-голям и не се използваше от плеъра; премахнат е от активната доставка във v0.14.1. Указанията под клипа са преведени на BG/EN/DE. При неуспешно зареждане остават изображението и писмените инструкции.

Service Worker кешира само изрично описаните версии на публичните клипове при първо пускане, без предварително изтегляне при инсталиране. Запазва само пълни HTTP 200 отговори и създава правилни HTTP 206 отговори за търсене/офлайн възпроизвеждане; 206/грешки не се запазват като пълен файл. Недостатъчен кеш не прекъсва онлайн възпроизвеждането. Изчистване или отнемане на браузърното място може да премахне офлайн копието.
