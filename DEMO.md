# Демонстрация за оценяване — FORME

1. Отвори приложението на телефон и покажи адаптивната навигация.
2. Тренировки → избери „Йога“ → резултатите стават 2; избери „До 10 мин“ → няма съвпадение; премахни филтъра.
3. Отвори „Силна основа“ → настрой 10 секунди работа и 5 секунди почивка → Старт → Пауза → Продължи → Следващо → Рестарт. Покажи текуща/следваща стъпка, напредък и звук по избор.
4. Упражнения → потърси „планк“ → отвори детайлите → покажи двата кадъра, по-лесния вариант и източника → добави в любими.
5. Хранене → отвори пилешки гърди → сравни 100 г и 200 г → добави към хранене.
6. Сглоби хранене → добави ориз → въведи `-20` (грешка) → поправи на `150` (изчислението се обновява) → премахни и добави отново.
7. Допълнителна функция #2 → дай име „След тренировка“, запази храненето, зареди го от „Запазени хранения“.
8. Допълнителна функция #1 → Моят план → постави „Силна основа“ за понеделник и „Slow Reset“ за вторник → презареди → изборите остават.
9. Любими → покажи запазеното упражнение → презареди → още е там.
10. Покажи GitHub repository, commits, Issue, branch, PR, README и публикувания линк.

За защита без AI: `core.js` съдържа `calculateForGrams`, `sumMeal` и `validateGrams`; `app.js` съдържа `tickPlayer`, `transitionPlayer`, `renderPlayer`, `localStorage` и навигацията; `data.js` съдържа каталог с упражнения, програми и храни.
