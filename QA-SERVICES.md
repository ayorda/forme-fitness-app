# Проверки на Programs / Personal Coaching 3.5

v0.11.0 проверява подготвителната архитектура от [SERVICES-ARCHITECTURE.md](./SERVICES-ARCHITECTURE.md). Не активира покупки/треньорска услуга. Положителните права, програми и назначения са **само синтетични локални Emulator fixtures**, без production данни/роля/покупка/писма.

## Повторими автоматични проверки

- `node --test test.js *.test.js`: пълният набор и 16 нови unit теста за точни пътища, SDK server-only четене, проверен акаунт, неизвестни продукти/path injection, schema/типове/граници, отделен coach UID, замразено копие и отказ на закъснели резултати след смяна/изход/offline.
- `node --check services.js` и всички останали production JS файлове; CI регистрира новия модул и тестове. Версиите, кешът, документацията, трите езика и HTML ресурсите се проверяват от съществуващите тестове.
- `npx -y firebase-tools@15.36.0 emulators:exec --only firestore --project demo-forme-sync "node qa/firestore-rules.mjs"`: **197 действителни Firestore твърдения** (76 съществуващи +121 за Services). QA файлът изтрива само локалната demo база и отказва изпълнение без FIRESTORE_EMULATOR_HOST=127.0.0.1:8080.
- Firebase rules syntax validation и CLI `deploy --only firestore --dry-run` преди публикуване на правилата. Readback трябва да съвпадне с проверения файл. Не се променят billing, Auth providers, IAM, Storage или платени услуги.

## Матрица за локални права

| Сценарий | Очакване |
| --- | --- |
| Guest/непотвърден/чужд акаунт | Отказ за всички service документи. |
| Собствен active grant | Чете точно собствената програма/версия; Pro сам не дава това право. |
| Revoked grant | Клиентът вижда своята grant история; четене на програмата е отказано. |
| Допълнителни полета/грешен ID/тип/дата/oversize | Отказ. |
| Клиент с назначение | Чете своите plan/feedback и история при paused/ended/consent:false. |
| Одобрен и точно назначен треньор | Чете само active/consented/в срок назначение и notes. |
| Друг/непотвърден/без роля/с изтекла или невалидна роля треньор | Отказ. |
| Consent:false / paused / ended / бъдещ start / изтекъл end | Следващо четене от треньора отказано; собствената история остава за клиента. |
| Delete marker на клиента | Отказ за всички негови services, включително достъп на треньора. |
| Delete marker на треньора | Отказ за треньора; клиентът запазва собствената история. |
| Coach → личен cloud snapshot / чужд grant | Отказ. |
| Клиентски create/update/delete, колекции/списъци | Отказ за клиент и треньор. |

Браузърният SDK тест трябва да използва официалния локално пакетиран SDK, реални Auth/Firestore Emulator отговори и същия named App като приложението. Проверява exact reads, canonical revocation/consent withdrawal и повторно влизане в друг акаунт; unit mock не се брои за това.

## Финален ръчен преглед

1. Отвори FORME, презареди и отвори човечето → „Програми и Personal Coaching“; директният маршрут е `#services`.
2. На BG/EN/DE трябва да има три направления „В подготовка“ и обяснение, че Coaching е бъдеща работа с реален треньор. Няма цени, покупка, записване или upload на лични клипове.
3. Използвай връзките към упражненията и безплатните програми/прогреса. Гост режимът и старите локални записи трябва да работят.
4. След първо онлайн зареждане провери новата страница офлайн. Това проверява публичния каталог; частните бъдещи материали не се зареждат офлайн.
5. На iPhone провери четимостта и връщането с Back в Safari и отделно Home Screen PWA. Това ново UI приемане още не е потвърдено от собственика. Вече приетият базов тест за запазен вход не се иска повторно.

Няма действително проведен многодневен/рестарт на физически телефон тест за това издание. Не се изисква и не бива да се предоставя лична парола. Бъдещи реални Coaching/платежни/медийни потоци се проверяват едва след изпълнение на условията преди активиране.
