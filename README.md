# FORME — Тренировки и хранене

**Безплатно, мобилно PWA приложение на български** за калистеника, йога, мобилност и ориентиране в храненето.

- **Работеща версия:** https://ayorda.github.io/forme-fitness-app/
- **GitHub:** _Това хранилище е изходният код на публикуваната версия._
- **Бюджет:** 0 € — без платен домейн, хостинг, API, абонамент или изображения.
- **Срок по задание:** 01.11.2026, 23:59, българско време.

## Мобилна навигация

На телефон основните секции са непосредствено под горната лента с логото FORME. При превъртане остават в горната част на екрана.

## Функции

1. **Избор на занимание:** направление, ниво, налично време и оборудване; реално филтрира 6 готови програми.
2. **24 упражнения:** категории, ниво, оборудване, две демонстрационни снимки, кратки инструкции, по-лесен вариант, източник; търсене и филтриране.
3. **Режим на изпълнение:** текущо и следващо упражнение, кръгове, напредък, работен/почивен таймер, настройка на секунди, Старт/Пауза/Продължи/Следващо/Рестарт, звук по избор. Таймерът използва реално време и наваксва след връщане към раздела.
4. **30 храни:** протеини, въглехидрати, мазнини, плодове и зеленчуци; състояние на храната, 100 г и избран грамаж, kcal/протеин/въглехидрати/мазнини/фибри, източник.
5. **Сглоби хранене:** няколко храни, редактиране на грамаж, премахване, мигновено обновяване и съобщения за невалидни стойности.
6. **Любими:** запазване на упражнения и тренировки в `localStorage` на устройството.
7. **Допълнителна функция #1 — Седмичен план:** избор на бъдещо занимание за всеки от 7 дни; запазва се локално. Не е тренировъчен дневник.
8. **Допълнителна функция #2 — Запазени хранения:** потребителят запазва комбинация с име и я зарежда по-късно; запазва се локално.

## Инсталиране на телефон (след публикуване)

- **Android / Chrome:** отвори публикувания HTTPS адрес → менюто на Chrome → **Инсталиране на приложението** или **Добавяне към началния екран**.
- **iPhone / Safari:** отвори публикувания HTTPS адрес → **Споделяне** → **Добавяне към Начален екран** → **Добавяне**.
- За инсталиране и офлайн кеширане е необходим публикуван HTTPS адрес. Самостоятелният HTML демофайл не е инсталируема PWA версия.
- Основният интерфейс и данните могат да се кешират за офлайн достъп след първо успешно зареждане. Външните изображения на упражнения може да изискват интернет.

## Стартиране

### Най-лесно (локално)

1. Разархивирайте файловете в една папка.
2. Отворете `index.html` с Chrome, Firefox или Edge. Приложението е изцяло клиентско и не изисква инсталация.
3. За по-надеждно локално тестване: отворете терминал в папката и изпълнете `python -m http.server 8000`, после посетете `http://localhost:8000`.

### Публикуване в GitHub Pages

1. В GitHub създайте **Public** repository с име `forme-fitness-app`.
2. В `Add file → Upload files` качете **разархивираните файлове**, включително `index.html`, в корена на хранилището. Не качвайте ZIP като единствен файл.
3. Натиснете **Commit changes**.
4. В `Settings → Pages` изберете `Deploy from a branch`, `main`, `/ (root)` и **Save**.
5. Изчакайте GitHub Pages да публикува адрес във формат `https://USERNAME.github.io/forme-fitness-app/`.
6. Отворете адреса на телефон и компютър; впишете го в този README.

GitHub Pages изисква публично хранилище при GitHub Free. Използвайте само относителни пътища, така че приложението да работи в поддиректорията на проекта.

## Проверка

В папката с файловете изпълнете:

```bash
node --test test.js pwa.test.js
```

Тестовете покриват хранителни изчисления, грамаж, грешни стойности, филтри и форматиране на таймера. Ръчни проверки: мобилен изглед, филтри, всички контроли на таймера, звуков сигнал, фонова пауза, запазване след презареждане и двете допълнителни функции.

## Известни ограничения

- **Няма акаунти или синхронизация.** Любими, седмичен план и запазени хранения се пазят само в същия браузър и устройство; могат да се загубят при изчистване на данните.
- **Няма тренировъчен дневник**, защото не е част от заданието.
- **Хранителните данни са ориентировъчни.** Пакетирани продукти, сортове, сурови/сготвени състояния могат да се различават. Липсва финален независим одит на всички 30 източника.
- **Снимките на упражненията изискват интернет**, защото са външно хоствани; при липса се показва резервен символ.
- **Звукът може да е ограничен** от настройките на браузъра, особено във фонов режим. Самият таймер наваксва според часовника.
- **Няма медицински препоръки или персонализирана диагностика.** Упражненията се изпълняват според възможностите, без болка.
- **Няма публикуван линк, докато GitHub Pages не бъде настроен. PWA инсталацията трябва да се провери на реален телефон след публикуване.**

## GitHub история и защита

За пълно покриване на тестовото задание са необходими смислени commits и поне един цикъл **Issue → отделен branch → Pull Request**, с описан тест. Пример:

- Issue: `Подобряване на съобщенията при невалиден грамаж`.
- Branch: `fix/grams-validation`.
- PR: `По-ясни грешки при въвеждане на грамаж`.
- Проверка: `node --test test.js pwa.test.js`, плюс ръчен тест с `-20`, `abc` и `150` грама.

**Важно:** кратката защита и промяната на живо се извършват самостоятелно, без AI. Трябва да можете да покажете `core.js` (хранителни изчисления), `app.js` (таймер, localStorage и UI) и `data.js` (каталози).
